# VisualMD Prompts & AI Agent Skills

This directory contains everything you need to prompt any LLM (Gemini, Claude, GPT-4, DeepSeek, Cursor, Ollama) to output token-efficient VisualMD content.

## Available Resources:

1. **`skill.md`**:
   - Universal tool/skill description for agentic environments (Antigravity, Claude Desktop, OpenAI GPTs, Cursor Rules).
   - Drop this into your agent's skill directory or load it as a project instruction.

2. **`VisualMDStandard.md`**:
   - The full, comprehensive specification reference explaining every tag, parameter, and fallback behavior.
   - Attach or upload this file to any chat session at the start.

3. **`system-prompt.txt`**:
   - A ready-to-copy, token-compact system prompt.
   - Paste directly into ChatGPT Custom Instructions, Claude System Prompt, or local LLM system fields.
